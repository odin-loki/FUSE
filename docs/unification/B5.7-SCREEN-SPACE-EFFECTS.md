## Components

| Component | Location | Notes |
|-----------|----------|-------|
| `SSAOParams` | `Compute/include/fuse/compute/screen_space_effects.hpp` | HBAO-style SSAO params; depth/normal in, AO out |
| `SSRParams` | same | Depth, normal, roughness, scene colour in; SSR out |
| `SSGIParams` | same | SSGI stub tier — bounce budget + intensity |
| `launch_ssao` / `launch_ssr` / `launch_ssgi` | `Compute/src/screen_space_effects_host.cpp` | Host launcher — CPU reference or CUDA stub kernel |
| `submit_ssao_job` / `submit_ssr_job` / `submit_ssgi_job` | `Compute/include/fuse/compute/screen_space_effects_job.hpp` | Wrap launchers in `CUDAJobDesc` → `submit_cuda` |
| `ssao.cu` / `ssr.cu` / `ssgi.cu` | `Compute/kernels/` | Placeholder `__global__` kernels when toolkit present |
| `ssao_center_sample` / `ssr_center_sample` / `ssgi_center_sample` | `Compute/src/screen_space_effects_cpu.cpp` | CPU reference center-pixel samples for unit tests |

### Backend modes

```cpp
enum class ScreenSpaceEffectsMode : u8 { Stub, CpuReference, Cuda };
```

| Mode | When | Behaviour |
|------|------|-----------|
| **CpuReference** | `FUSE_BUILD_CUDA=ON`, no toolkit | Host reference samples + no-op launches |
| **Cuda** | Toolkit found (`FUSE_HAS_CUDA=1`) | Launches placeholder kernels via B2.6 managed stream |
| **Stub** | `FUSE_BUILD_CUDA=OFF` | `fuse_compute` not built |

Job workers call `submit_ssao_job` / `submit_ssr_job` / `submit_ssgi_job`; they never include `<cuda_runtime.h>`.

## Deferred pipeline slot

The render graph already reserves a CUDA pass for screen-space AO:

- `DeferredPassId::ScreenSpaceAo` — name `"screen_space_ao"` in `frame_pipeline.cpp`
- G-buffer attachments set `textureDesc.cudaInterop = true` (B5.2)

Wiring the deferred execute path to call `submit_ssao_job` / `submit_ssr_job` remains future work (B2.5 graph execution is still stub recording). Do **not** add new `DeferredPassId` values — pass count stays 16.
