# Engine Development Plan — Phase 4: Physics Engine

**Duration:** 5–6 weeks with AI-assisted coding  
**Prerequisite:** Phase 3 complete. ECS running, BVH and SVO built, scene renders correctly at target framerate.  
**Goal:** A fully GPU-parallel physics engine. Rigid bodies, analytic and SDF-based collision, a CUDA constraint solver, soft bodies, and voxel destruction via SVO carving. By end of phase: objects fall, collide, stack, slide, and shatter. Physics runs entirely on the CUDA compute stream — zero CPU bottleneck on the simulation side.

---

## 4.1 — Physics Architecture

### Design Philosophy

Traditional physics engines (Bullet, PhysX, Havok) are CPU-centric with GPU acceleration bolted on. This engine inverts that model. The simulation is a CUDA-first pipeline. The CPU submits work, the GPU owns the data and runs the solver. Results are written back to ECS component arrays (managed memory) and consumed by the renderer without an explicit readback.

### Pipeline Per Frame

```
CPU Frame N:
├── Collect RigidBody + Transform components → GPU integration buffers
├── Submit BroadPhase kernel (spatial hash)
├── Submit NarrowPhase kernel (analytic + GJK)
├── Submit ConstraintSolver kernels (PBD iterations)
├── Submit IntegrateState kernel
├── Signal physics_done semaphore
└── Continue with render submission

GPU (CUDA Physics Stream):
├── BroadPhaseKernel   — O(n) spatial hash, produces candidate pairs
├── NarrowPhaseKernel  — O(k) exact collision, produces contact manifolds
├── PBDSolverKernel    — N iterations of position-based constraint resolution
├── IntegrateKernel    — Euler integration, damping, sleep detection
└── WriteBackKernel    — update managed-memory Transform + RigidBody arrays
```

### Data Layout

All physics data is stored in Structure-of-Arrays (SoA) layout for coalesced GPU memory access. Never Array-of-Structures in hot paths.

```cpp
// physics/physics_data.hpp
#pragma once
#include "../core/types.hpp"
#include "../core/math/vec.hpp"

// SoA rigid body state — GPU resident, managed memory
struct RigidBodySoA {
  // Position and orientation
  vec3*  positions;           // world-space centre of mass
  quat*  orientations;
  vec3*  linear_velocities;
  vec3*  angular_velocities;

  // Mass properties
  f32*   inv_masses;          // 0 = static
  mat3*  inv_inertia_world;   // inertia tensor in world space

  // Forces accumulated this frame
  vec3*  forces;
  vec3*  torques;

  // Material properties
  f32*   restitutions;
  f32*   friction_static;
  f32*   friction_dynamic;

  // State flags
  u32*   flags;               // bitfield: STATIC | SLEEPING | TRIGGER | KINEMATIC

  // PBD position prediction
  vec3*  predicted_positions;
  quat*  predicted_orientations;

  u32    count;
  u32    capacity;

  static RigidBodySoA allocate(u32 capacity);
  static void         free(RigidBodySoA& soa);
};

// Collision shape descriptor — GPU resident
struct CollisionShapeSoA {
  u32*  types;            // 0=sphere 1=box 2=capsule 3=convex_hull 4=sdf_mesh 5=voxel
  vec3* params;           // type-specific params (radius, half-extents, etc.)
  u32*  body_indices;     // which rigid body owns this shape
  mat4* local_transforms; // shape offset from body centre

  u32   count;
};

enum RigidBodyFlags : u32 {
  RB_STATIC    = 1 << 0,
  RB_SLEEPING  = 1 << 1,
  RB_TRIGGER   = 1 << 2,    // no collision response, only detection
  RB_KINEMATIC = 1 << 3,    // driven by animation, not physics
  RB_NO_GRAVITY= 1 << 4,
  RB_CCD       = 1 << 5,    // continuous collision detection
};
```

## 4.2 — Broad Phase: Spatial Hash

The broad phase finds candidate collision pairs in O(n). No BVH traversal here — the spatial hash is faster for large uniform distributions of dynamic bodies and maps perfectly to CUDA's parallel model.

### Spatial Hash Algorithm

```cpp
// physics/broadphase/spatial_hash.cuh
#pragma once
#include "../../core/types.hpp"
#include "../../core/math/vec.hpp"
#include "../physics_data.hpp"

struct SpatialHashParams {
  f32  cell_size;          // should be ~ 2× average body radius
  u32  table_size;         // prime number, >= 2 × body count
  u32  body_count;
};

struct CandidatePair {
  u32 body_a;
  u32 body_b;
};

// Phase 1: hash each body's AABB into overlapping cells
__global__ void build_hash_kernel(
  const vec3*         positions,
  const CollisionShapeSoA shapes,
  u32*                cell_keys,     // sorted cell hash per body
  u32*                body_values,   // body index per entry
  const SpatialHashParams params
);

// Phase 2: sort (cell_key, body_index) pairs by cell key — radix sort on GPU
void radix_sort_pairs(u32* keys, u32* values, u32 count, cudaStream_t stream);

// Phase 3: scan sorted list, emit candidate pairs for bodies sharing a cell
__global__ void find_pairs_kernel(
  const u32*          sorted_keys,
  const u32*          sorted_values,
  u32                 entry_count,
  CandidatePair*      pairs,
  u32*                pair_count,    // atomic counter
  u32                 max_pairs

  const RigidBodySoA& bodies,
  const CollisionShapeSoA& shapes,
  CandidatePair* out_pairs,
  u32 max_pairs,
  const SpatialHashParams& params,
  cudaStream_t stream
```

### Hash Function

```cpp
// Spatial hash — maps 3D cell coords to table index
ENGINE_HOST_DEVICE inline u32
spatial_hash(i32 cx, i32 cy, i32 cz, u32 table_size) {
  // Large primes for good distribution
  constexpr u32 p1 = 73856093u;
  constexpr u32 p2 = 19349663u;
  constexpr u32 p3 = 83492791u;
  return ((u32)(cx * p1) ^ (u32)(cy * p2) ^ (u32)(cz * p3)) % table_size;
}

ENGINE_HOST_DEVICE inline ivec3
world_to_cell(vec3 pos, f32 cell_size) {
  return { (i32)floorf(pos.x / cell_size),
           (i32)floorf(pos.y / cell_size),
           (i32)floorf(pos.z / cell_size) };
}
```

## 4.3 — Narrow Phase: Exact Collision Detection

For each candidate pair from the broad phase, compute the exact contact manifold. Use closed-form analytic solutions where available — only fall back to iterative algorithms (GJK/EPA) for convex hulls.

### Analytic Collision Dispatch

```cpp
// physics/narrowphase/collision_dispatch.cuh
#pragma once
#include "../../core/types.hpp"
#include "../../core/math/vec.hpp"
#include "../physics_data.hpp"

// Contact manifold — result of narrow phase for one pair
struct ContactManifold {
  vec3  contact_point;      // world-space point on body A surface
  vec3  contact_normal;     // from body B toward body A
  f32   penetration_depth;  // positive = overlapping
  u32   body_a, body_b;
  bool  valid;
};

// Closed-form sphere-sphere — exact, no iteration
ENGINE_HOST_DEVICE inline ContactManifold
collide_sphere_sphere(vec3 pos_a, f32 r_a, vec3 pos_b, f32 r_b,
                      u32 idx_a, u32 idx_b) {
  vec3 diff = {pos_a.x-pos_b.x, pos_a.y-pos_b.y, pos_a.z-pos_b.z};
  f32  dist  = diff.length();
  f32  sum_r = r_a + r_b;
  if (dist >= sum_r) return {.valid = false};
  vec3 normal = (dist > 1e-6f) ? diff * (1.f / dist) : vec3{0,1,0};
  return {
    .contact_point  = {pos_b.x + normal.x*r_b,
                       pos_b.y + normal.y*r_b,
                       pos_b.z + normal.z*r_b},
    .contact_normal = normal,
    .penetration_depth = sum_r - dist,
    .body_a = idx_a, .body_b = idx_b,
    .valid  = true
  };
}

// Closed-form sphere-plane — exact
ENGINE_HOST_DEVICE inline ContactManifold
collide_sphere_plane(vec3 sphere_pos, f32 sphere_r,
                     vec3 plane_normal, f32 plane_d,
                     u32 idx_sphere, u32 idx_plane) {
  f32 dist = sphere_pos.dot(plane_normal) - plane_d;
  if (dist >= sphere_r) return {.valid = false};
  return {
    .contact_point  = {sphere_pos.x - plane_normal.x * sphere_r,
                       sphere_pos.y - plane_normal.y * sphere_r,
                       sphere_pos.z - plane_normal.z * sphere_r},
    .contact_normal = plane_normal,
    .penetration_depth = sphere_r - dist,
    .body_a = idx_sphere, .body_b = idx_plane,
    .valid  = true
  };
}

// Closed-form capsule-capsule — exact
ENGINE_HOST_DEVICE ContactManifold
collide_capsule_capsule(vec3 a0, vec3 a1, f32 ra,
                        vec3 b0, vec3 b1, f32 rb,
                        u32 idx_a, u32 idx_b);

// Closed-form sphere-box — exact
ENGINE_HOST_DEVICE ContactManifold
collide_sphere_box(vec3 sphere_pos, f32 sphere_r,
                   vec3 box_center, vec3 box_half, quat box_rot,
                   u32 idx_sphere, u32 idx_box);

// SDF-based collision — for mesh SDF and voxel SDF bodies
// Uses SDF gradient as contact normal — analytically exact
ENGINE_HOST_DEVICE ContactManifold
collide_sdf_sphere(cudaSurfaceObject_t sdf_volume, vec3 sphere_pos, f32 sphere_r,
                   vec3 sdf_origin, f32 sdf_voxel_size,
                   u32 idx_sdf, u32 idx_sphere);

// GJK + EPA for convex hull pairs — iterative fallback
ENGINE_HOST_DEVICE ContactManifold
collide_convex_convex(const vec3* hull_a_verts, u32 count_a, const mat4& transform_a,
                      const vec3* hull_b_verts, u32 count_b, const mat4& transform_b,
                      u32 idx_a, u32 idx_b);

// Dispatch kernel — runs one thread per candidate pair
__global__ void narrow_phase_kernel(
  const CandidatePair*     pairs,
  u32                      pair_count,
  const RigidBodySoA       bodies,
  const CollisionShapeSoA  shapes,
  ContactManifold*         manifolds,
  u32*                     manifold_count   // atomic
);
```

### GJK Implementation

```cpp
// physics/narrowphase/gjk.cuh

// Support function — furthest point in direction d
ENGINE_HOST_DEVICE inline vec3
support(const vec3* verts, u32 count, vec3 d) {
  f32  max_dot = -1e30f;
  vec3 best    = verts[0];
  for (u32 i = 0; i < count; i++) {
    f32 dot = verts[i].dot(d);
    if (dot > max_dot) { max_dot = dot; best = verts[i]; }
  }
  return best;
}

// Minkowski difference support
ENGINE_HOST_DEVICE inline vec3
minkowski_support(const vec3* a, u32 na, const mat4& ta,
                  const vec3* b, u32 nb, const mat4& tb, vec3 d) {
  vec3 sa = ta.transform_point(support(a, na, ta.inverse().transform_dir(d)));
  vec3 sb = tb.transform_point(support(b, nb, tb.inverse().transform_dir({-d.x,-d.y,-d.z})));
  return {sa.x-sb.x, sa.y-sb.y, sa.z-sb.z};
}

// GJK intersection test — returns true if shapes overlap
ENGINE_HOST_DEVICE bool gjk_intersect(
  const vec3* a, u32 na, const mat4& ta,
  const vec3* b, u32 nb, const mat4& tb
);

// EPA — Expanding Polytope Algorithm — extracts penetration depth from GJK simplex
ENGINE_HOST_DEVICE ContactManifold epa(
  const vec3* a, u32 na, const mat4& ta,
  const vec3* b, u32 nb, const mat4& tb,
  u32 idx_a, u32 idx_b
);
```

## 4.4 — Constraint Solver: Position Based Dynamics

PBD (Position Based Dynamics) is chosen over traditional impulse-based solvers because it is unconditionally stable, parallelises naturally on CUDA, and produces visually plausible results with a low iteration count. Each constraint directly corrects positions rather than accumulating impulses — no velocity-level instability.

### PBD Overview

```
Each frame:
1. Apply external forces → predict new positions
2. For N iterations:
   a. For each contact constraint: project positions apart (parallel)
   b. For each joint constraint: project joint limits (parallel)
   c. For each friction constraint: apply tangential correction
3. Update velocities from position deltas
4. Apply damping and sleep detection
```

### PBD Kernels

### XPBD Contact Resolution

Extended PBD (XPBD) adds a compliance parameter that gives physically correct stiffness scaling independent of timestep and iteration count.

```cpp
__device__ void resolve_contact_xpbd(
  RigidBodySoA& bodies,
  const ContactManifold& c,
  f32 dt,
  f32 compliance
) {
  if (!c.valid) return;

  u32 a = c.body_a, b = c.body_b;
  f32 inv_mass_a = bodies.inv_masses[a];
  f32 inv_mass_b = bodies.inv_masses[b];
  f32 w_sum      = inv_mass_a + inv_mass_b;
  if (w_sum < 1e-10f) return;

  // Current separation along normal
  vec3 pa = bodies.predicted_positions[a];
  vec3 pb = bodies.predicted_positions[b];
  vec3 diff = {pa.x-pb.x, pa.y-pb.y, pa.z-pb.z};
  f32  C = diff.dot(c.contact_normal) - c.penetration_depth;
  if (C >= 0.f) return;   // no penetration

  // XPBD: compliance-adjusted Lagrange multiplier
  f32 alpha      = compliance / (dt * dt);
  f32 delta_lambda = -C / (w_sum + alpha);

  // Positional correction
  vec3 dp = {c.contact_normal.x * delta_lambda,
             c.contact_normal.y * delta_lambda,
             c.contact_normal.z * delta_lambda};

  // Atomic adds — multiple contacts may affect same body
  atomicAdd(&bodies.predicted_positions[a].x,  dp.x * inv_mass_a);
  atomicAdd(&bodies.predicted_positions[a].y,  dp.y * inv_mass_a);
  atomicAdd(&bodies.predicted_positions[a].z,  dp.z * inv_mass_a);
  atomicAdd(&bodies.predicted_positions[b].x, -dp.x * inv_mass_b);
  atomicAdd(&bodies.predicted_positions[b].y, -dp.y * inv_mass_b);
  atomicAdd(&bodies.predicted_positions[b].z, -dp.z * inv_mass_b);

  // Friction — tangential correction
  vec3 rel_v = {(pa.x-pb.x)/dt, (pa.y-pb.y)/dt, (pa.z-pb.z)/dt};
  f32  vn    = rel_v.dot(c.contact_normal);
  vec3 vt    = {rel_v.x - c.contact_normal.x*vn,
                rel_v.y - c.contact_normal.y*vn,
                rel_v.z - c.contact_normal.z*vn};
  f32  vt_len = vt.length();
  if (vt_len > 1e-6f) {
    f32  friction_coeff = 0.4f;  // from material table in production
    f32  friction_corr  = fminf(friction_coeff * fabsf(delta_lambda), vt_len * w_sum) / w_sum;
    vec3 vt_dir = vt * (1.f / vt_len);
    atomicAdd(&bodies.predicted_positions[a].x, -vt_dir.x * friction_corr * inv_mass_a);
    atomicAdd(&bodies.predicted_positions[a].y, -vt_dir.y * friction_corr * inv_mass_a);
    atomicAdd(&bodies.predicted_positions[a].z, -vt_dir.z * friction_corr * inv_mass_a);
  }
}
```

## 4.6 — Continuous Collision Detection

For fast-moving objects, discrete collision detection misses contacts between frames (tunnelling). CCD sweeps the shape's trajectory and finds the earliest time-of-impact.

```cpp
// physics/ccd/ccd.cuh
#pragma once
#include "../physics_data.hpp"

struct TOIResult {
  f32  toi;           // time of impact in [0,1] — fraction of frame timestep
  vec3 contact_point;
  vec3 contact_normal;
  u32  body_a, body_b;
  bool valid;
};

// Sphere swept against sphere — exact closed-form TOI
ENGINE_HOST_DEVICE inline TOIResult
swept_sphere_sphere(
  vec3 pos_a0, vec3 vel_a, f32 ra,
  vec3 pos_b0, vec3 vel_b, f32 rb
) {
  // Relative motion — solve quadratic for first intersection time
  vec3 rel_pos = {pos_a0.x-pos_b0.x, pos_a0.y-pos_b0.y, pos_a0.z-pos_b0.z};
  vec3 rel_vel = {vel_a.x-vel_b.x, vel_a.y-vel_b.y, vel_a.z-vel_b.z};
  f32  r_sum   = ra + rb;

  f32  a = rel_vel.dot(rel_vel);
  f32  b = 2.f * rel_pos.dot(rel_vel);
  f32  c = rel_pos.dot(rel_pos) - r_sum * r_sum;

  if (a < 1e-10f) return {.valid = false};  // parallel motion

  f32 disc = b*b - 4.f*a*c;
  if (disc < 0.f) return {.valid = false};  // no intersection

  f32  sqrt_disc = sqrtf(disc);
  f32  t0 = (-b - sqrt_disc) / (2.f * a);
  f32  t1 = (-b + sqrt_disc) / (2.f * a);

  f32 toi = (t0 >= 0.f) ? t0 : t1;
  if (toi < 0.f || toi > 1.f) return {.valid = false};

  vec3 hit_a = {pos_a0.x+vel_a.x*toi, pos_a0.y+vel_a.y*toi, pos_a0.z+vel_a.z*toi};
  vec3 hit_b = {pos_b0.x+vel_b.x*toi, pos_b0.y+vel_b.y*toi, pos_b0.z+vel_b.z*toi};
  vec3 n     = vec3{hit_a.x-hit_b.x, hit_a.y-hit_b.y, hit_a.z-hit_b.z}.normalized();

  return {.toi=toi, .contact_point=hit_b, .contact_normal=n,
          .body_a=0, .body_b=0, .valid=true};
}
```

## 4.7 — Voxel Destruction

Destruction is the killer feature of the SVO. When a rigid body collides with a voxel entity above a destruction threshold, a sphere-carve is issued to the SVO, surface voxels are extracted as a new mesh, and the debris becomes new rigid bodies.

### Destruction Pipeline


### Debris Spawning

```cpp
void DestructionSystem::apply_destruction(
  const DestructionEvent& e,
  SVO& svo,
  Registry& reg,
  ResourceManager& resources
) {
  // 1. Carve sphere from SVO
  svo.carve(e.impact_point, e.carve_radius);

  // 2. Extract changed surface region as mesh (dual contouring)
  AABB affected_region = {
    {e.impact_point.x - e.carve_radius * 2,
     e.impact_point.y - e.carve_radius * 2,
     e.impact_point.z - e.carve_radius * 2},
    {e.impact_point.x + e.carve_radius * 2,
     e.impact_point.y + e.carve_radius * 2,
     e.impact_point.z + e.carve_radius * 2}
  };

  std::vector<vec3> verts;
  std::vector<u32>  indices;
  svo.extract_mesh_region(affected_region, verts, indices);

  if (verts.empty()) return;

  // 3. Cluster disconnected fragments (flood fill on extracted mesh)
  auto fragments = cluster_disconnected(verts, indices);

  // 4. Spawn each fragment as a new rigid body entity
  for (auto& frag : fragments) {
    if (frag.verts.size() < 4) continue;  // too small — discard

    f32  frag_mass     = (f32)frag.verts.size() * 0.1f;  // proportional to size
    vec3 frag_center   = compute_centroid(frag.verts);
    vec3 debris_vel    = {e.impact_normal.x * -e.impulse * 0.3f + random_f32(-2,2),
                          e.impact_normal.y * -e.impulse * 0.3f + random_f32(1, 5),
                          e.impact_normal.z * -e.impulse * 0.3f + random_f32(-2,2)};

    spawn_debris(frag.verts, frag.indices, frag_center, frag_mass,
                 debris_vel, reg, resources);
  }
}
```

### Particle System

### Cloth Solver Kernel

```cpp
// physics/softbody/cloth_kernels.cuh

__global__ void cloth_predict_kernel(ParticleSoA p, f32 dt, vec3 gravity) {
  u32 i = blockIdx.x * blockDim.x + threadIdx.x;
  if (i >= p.count) return;
  if (p.inv_masses[i] == 0.f) return;  // pinned particle

  p.velocities[i].x += gravity.x * dt;
  p.velocities[i].y += gravity.y * dt;
  p.velocities[i].z += gravity.z * dt;
  p.prev_positions[i] = p.positions[i];
  p.positions[i].x   += p.velocities[i].x * dt;
  p.positions[i].y   += p.velocities[i].y * dt;
  p.positions[i].z   += p.velocities[i].z * dt;
}

__global__ void cloth_solve_constraints_kernel(
  ParticleSoA p,
  const ParticleConstraint* constraints,
  u32 count,
  f32 dt
) {
  u32 ci = blockIdx.x * blockDim.x + threadIdx.x;
  if (ci >= count) return;

  const ParticleConstraint& c = constraints[ci];
  vec3 pa = p.positions[c.a];
  vec3 pb = p.positions[c.b];
  vec3 diff = {pa.x-pb.x, pa.y-pb.y, pa.z-pb.z};
  f32  dist = diff.length();
  if (dist < 1e-6f) return;

  f32  alpha  = c.compliance / (dt * dt);
  f32  w_sum  = p.inv_masses[c.a] + p.inv_masses[c.b];
  f32  C      = dist - c.rest_length;
  f32  lambda = -C / (w_sum + alpha);
  vec3 n      = diff * (1.f / dist);

  atomicAdd(&p.positions[c.a].x,  n.x * lambda * p.inv_masses[c.a]);
  atomicAdd(&p.positions[c.a].y,  n.y * lambda * p.inv_masses[c.a]);
  atomicAdd(&p.positions[c.a].z,  n.z * lambda * p.inv_masses[c.a]);
  atomicAdd(&p.positions[c.b].x, -n.x * lambda * p.inv_masses[c.b]);
  atomicAdd(&p.positions[c.b].y, -n.y * lambda * p.inv_masses[c.b]);
  atomicAdd(&p.positions[c.b].z, -n.z * lambda * p.inv_masses[c.b]);
}
```

### Frame Step Implementation

```cpp
void PhysicsManager::step(Registry& registry, f32 dt, StreamManager& streams) {
  PROFILE_SCOPE("PhysicsManager::step");
  cudaStream_t s = streams.get(CUDAStream::Physics);

  // 1. Sync ECS → SoA (managed memory — no explicit copy needed if ECS is managed)
  sync_ecs_to_soa_(registry);

  // 2. Run full solver on physics stream
  solver_.step(soa_, shapes_, desc_.solver, dt, s);

  // 3. Optional n-body forces
  if (desc_.enable_nbody) {
    compute_nbody_forces(soa_.positions, soa_.inv_masses,  // 1/mass → compute mass
                         soa_.count, soa_.forces,
                         desc_.nbody, s);
  }

  // 4. Write results back to ECS (async — stream ordering guarantees correctness)
  sync_soa_to_ecs_(registry);

  // 5. Process destruction events on CPU (mesh re-extraction is CPU work)
  if (desc_.enable_destruction && !destruction_events_.empty()) {
    cudaStreamSynchronize(s);  // need SVO state finalised before CPU processes
    process_destruction_events_(registry, *resources_);
    destruction_events_.clear();
  }
}
```
