## 3.1 — Entity-Component-System Architecture

The ECS is the engine's data model. Everything that exists in the game world is an entity. Everything an entity *is* or *does* is described by components. Systems process components in bulk. No inheritance, no virtual dispatch, no `GameObject` god objects.

### Design Principles

- **Archetype storage** — entities with the same component set share a contiguous memory block (archetype). Iteration over a component type is a linear scan through packed arrays. Cache miss rate approaches zero for bulk processing.
- **Handle-based identity** — entities are `EntityID` handles (index + generation). No raw pointers. Stale handles detected O(1).
- **CUDA-accessible component arrays** — archetypes backed by managed or pinned memory where physics and simulation components need GPU access.
- **No per-entity virtual calls** — systems are free functions or lambdas that receive typed component spans.
- **C++20 concepts** constrain all component and system types at compile time.

## 3.3 — Core Systems

Systems are free functions that operate on component arrays via `Registry::each`. They run on the job system. Dependencies between systems are declared explicitly so the scheduler can parallelise where safe.

### Transform System

```cpp
// ecs/systems/transform_system.hpp
#pragma once
#include "../entity.hpp"

class TransformSystem {
public:
  // Recomputes local_to_world for all dirty transforms
  // Parent transforms are resolved first — hierarchy traversal via topological sort
  static void update(Registry& reg);

private:
  static void update_recursive(Registry& reg, EntityID id, const mat4& parent_matrix);
};

// Implementation sketch
void TransformSystem::update(Registry& reg) {
  // First pass: collect all root transforms (parent == null)
  // Submit as jobs per-archetype — O(n) parallel
  reg.each_parallel<Transform>([&](EntityID id, Transform& t) {
    if (t.parent.valid() || !t.dirty) return;
    mat4 local = mat4::from_trs(t.position, t.rotation, t.scale);
    t.local_to_world = local;
    t.world_to_local = local.inverse_affine();
    t.dirty = false;
    // Propagate to children — deferred to second pass
  }, 512);
  // Second pass: children (ordered by depth in hierarchy)
  // ...
}
```

## 3.4 — Bounding Volume Hierarchy (BVH)

The BVH is the primary spatial acceleration structure for rendering culling, ray queries, and physics broad-phase overlap tests. Leaf nodes can be triangles, SDF primitives, or voxel chunks — the traversal algorithm is agnostic.

### BVH Node Layout

```cpp
// spatial/bvh.hpp
#pragma once
#include "../core/math/vec.hpp"
#include "../core/types.hpp"

// AABB — axis-aligned bounding box
struct AABB {
  vec3 min, max;

  ENGINE_HOST_DEVICE vec3  center()   const { return (min + max) * 0.5f; }
  ENGINE_HOST_DEVICE vec3  extents()  const { return (max - min) * 0.5f; }
  ENGINE_HOST_DEVICE f32   surface_area() const;
  ENGINE_HOST_DEVICE bool  contains(vec3 p) const;
  ENGINE_HOST_DEVICE bool  overlaps(const AABB& b) const;
  ENGINE_HOST_DEVICE AABB  merge(const AABB& b) const;
  ENGINE_HOST_DEVICE f32   ray_intersect(vec3 ro, vec3 inv_rd) const;  // returns t or -1
};

// Leaf node payload — what the BVH leaf points to
enum class BVHLeafType : u8 { Mesh, SDF, VoxelChunk, Light };

struct BVHLeaf {
  BVHLeafType type;
  EntityID    entity;
  u32         primitive_index;  // triangle index for Mesh, object index for SDF
};

// 32-byte BVH node — cache-line friendly
struct BVHNode {
  AABB aabb;           // 24 bytes
  u32  left_child;     // index into nodes array, or leaf index if is_leaf
  u32  right_child;
  u16  leaf_count;     // 0 = internal node, >0 = leaf
  u8   split_axis;     // 0=x, 1=y, 2=z
  u8   _pad;
};
static_assert(sizeof(BVHNode) == 40);
```

### BVH Builder

```cpp
// spatial/bvh_builder.hpp
#pragma once
#include "bvh.hpp"
#include <span>

struct BVHBuildDesc {
  u32  max_leaf_primitives = 4;

  bool parallel            = true;    // parallel build via job system

public:

  usize          node_count() const { return nodes_.size(); }
  usize          leaf_count() const { return leaves_.size(); }

  // GPU-resident copy for CUDA traversal
  BufferHandle   gpu_nodes;
  BufferHandle   gpu_leaves;
  void           upload_to_gpu(ResourceManager& resources);

private:
  std::vector<BVHNode> nodes_;

  u32  build_recursive(std::span<BVHLeaf> leaves, u32 depth);
  f32  sah_cost(const AABB& parent, const AABB& left, const AABB& right,
                u32 n_left, u32 n_right) const;

```

### SAH Split Algorithm

```cpp
u32 BVH::build_recursive(std::span<BVHLeaf> leaves, u32 depth) {
  u32 node_idx = (u32)nodes_.size();
  nodes_.push_back({});
  BVHNode& node = nodes_[node_idx];

  // Compute enclosing AABB
  node.aabb = leaves[0].aabb;
  for (auto& l : leaves.subspan(1)) node.aabb = node.aabb.merge(l.aabb);

  // Leaf if small enough or max depth
  if (leaves.size() <= desc_.max_leaf_primitives || depth > 32) {
    node.leaf_count = (u16)leaves.size();
    // store leaves inline
    return node_idx;
  }

  // SAH: try all 3 axes, pick lowest cost split
  f32 best_cost  = std::numeric_limits<f32>::max();
  u32 best_axis  = 0;
  u32 best_split = 0;

  for (u32 axis = 0; axis < 3; axis++) {
    // Sort along axis (pdqsort — O(n log n))
    std::sort(leaves.begin(), leaves.end(), [axis](const BVHLeaf& a, const BVHLeaf& b){
      return a.aabb.center().data[axis] < b.aabb.center().data[axis];
    });
    // Sweep left to right accumulating AABBs
    for (u32 s = 1; s < leaves.size(); s++) {
      AABB left_aabb  = leaves[0].aabb; for (u32 i=1;i<s;i++) left_aabb  = left_aabb.merge(leaves[i].aabb);
      AABB right_aabb = leaves[s].aabb; for (u32 i=s+1;i<leaves.size();i++) right_aabb = right_aabb.merge(leaves[i].aabb);
      f32 cost = sah_cost(node.aabb, left_aabb, right_aabb, s, (u32)leaves.size()-s);
      if (cost < best_cost) { best_cost = cost; best_axis = axis; best_split = s; }
    }
  }

  // Sort on best axis and split
  std::sort(leaves.begin(), leaves.end(), [best_axis](const BVHLeaf& a, const BVHLeaf& b){
    return a.aabb.center().data[best_axis] < b.aabb.center().data[best_axis];
  });

  node.split_axis  = (u8)best_axis;
  node.leaf_count  = 0;
  node.left_child  = build_recursive(leaves.subspan(0, best_split),           depth+1);
  node.right_child = build_recursive(leaves.subspan(best_split),               depth+1);
  return node_idx;
}
```

## 3.5 — Sparse Voxel Octree (SVO)

The SVO is the secondary spatial structure — used for voxel-based objects, destruction, and global illumination probe placement. Coexists with the BVH. The BVH contains SVO chunks as leaf nodes.

### SVO Node

```cpp
// spatial/svo.hpp
#pragma once
#include "../core/types.hpp"
#include "../core/math/vec.hpp"

// Each node covers a cubic region of space
// Internal nodes have 8 children (octants)
// Leaf nodes store voxel data
struct SVONode {
  u32  children[8];    // indices into node pool, 0 = empty
  u32  parent;
  u8   depth;
  bool is_leaf;
  // Leaf data — 8 voxels (2×2×2 sub-grid at leaf level)
  u32  voxel_data;     // packed RGBA, or index into voxel material table
  // SDF value stored at this node — enables SDF-voxel hybrid
  f32  sdf_value;
};

struct SVODesc {
  vec3  origin;          // world-space root origin
  f32   root_size;       // root cube side length in world units
  u32   max_depth;       // depth 10 = 1024³ voxels at leaf level
  bool  store_sdf;       // store distance field values at leaves
};

class SVO {
public:
  void  init(const SVODesc& desc, Allocator& alloc);
  void  destroy();

  // Insert/remove voxels
  void  set(ivec3 voxel_coord, u32 material);
  u32   get(ivec3 voxel_coord) const;
  void  fill(ivec3 min, ivec3 max, u32 material);
  void  carve(vec3 center, f32 radius);   // sphere carve — for destruction

  // O(log n) ray traversal
  bool  ray_cast(vec3 ro, vec3 rd, f32 max_t, ivec3& hit_voxel, vec3& hit_normal, f32& t) const;

  // Extract mesh from surface voxels (dual contouring — sharp features preserved)
  void  extract_mesh(std::vector<vec3>& verts, std::vector<u32>& indices) const;

  // SDF query — interpolates stored SDF values
  f32   sdf_query(vec3 world_pos) const;

  // GPU upload for CUDA ray traversal
  void  upload_to_gpu(ResourceManager& resources, BufferHandle& out_nodes, BufferHandle& out_data);

  usize node_count() const { return node_count_; }
  usize voxel_count() const;

private:
  SVODesc  desc_;
  SVONode* nodes_;    // pool allocator backed
  usize    node_count_;
  usize    node_capacity_;
  Allocator* alloc_;

  u32  allocate_node();
  u32  find_or_create_node(ivec3 voxel_coord, u32 depth);
  void update_sdf_at_node(u32 node_idx, u32 depth, vec3 node_center, f32 node_size);
};
```

### Scene Update Order

```cpp
void Scene::update(f32 dt) {
  // Systems run in dependency order via job system
  // Dependencies declared explicitly — parallelise where safe

  JobCounter transforms_done;
  JobScheduler::submit({
    .fn = [&]{ TransformSystem::update(registry_); },
    .counter = &transforms_done,
    .tag = "TransformSystem"
  });
  transforms_done.wait();

  // Camera update depends on transforms
  JobCounter cameras_done;
  JobScheduler::submit({
    .fn = [&]{ CameraSystem::update(registry_); },
    .counter = &cameras_done,
    .tag = "CameraSystem"
  });
  cameras_done.wait();

  // BVH refit depends on transforms
  // Physics broad phase depends on BVH — these run after
  refit_bvh_();
  // Physics runs in Phase 4
}
```

## 3.8 — Camera System

```cpp
// ecs/systems/camera_system.hpp
#pragma once
#include "../entity.hpp"

class CameraSystem {
public:
  // Recomputes view, projection, view_projection, frustum planes for active camera
  static void update(Registry& reg);

  // Free-camera controller — used in editor and debug builds
  static void update_free_camera(Registry& reg, const InputState& input, f32 dt,
                                 f32 move_speed = 10.f, f32 look_sensitivity = 0.2f);

private:
  static Camera::Frustum compute_frustum(const mat4& vp);
};

void CameraSystem::update(Registry& reg) {
  reg.each<Transform, Camera>([](EntityID id, Transform& t, Camera& cam) {
    if (!cam.is_active) return;

    // View matrix from transform — inverse of TRS
    cam.view = t.world_to_local;

    // Projection — reversed-Z for better depth precision at distance
    f32 f = 1.f / tanf(cam.fov_deg * 0.5f * 3.14159f / 180.f);
    cam.projection = mat4::perspective_reversed_z(f, cam.aspect_ratio,
                                                   cam.near_plane, cam.far_plane);
    cam.view_projection = cam.projection * cam.view;
    cam.frustum         = compute_frustum(cam.view_projection);
  });
}
```
