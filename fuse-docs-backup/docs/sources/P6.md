# Engine Development Plan — Phase 6: Editor

**Duration:** 5–6 weeks with AI-assisted coding  
**Prerequisite:** Phase 5 complete. Full rendering pipeline producing visually correct frames. Physics running. Scene serialisation working.  
**Goal:** A complete, professional-grade editor application built on ImGui. Scene hierarchy, property inspector, material editor, SDF sculpting tools, asset browser, in-viewport gizmos, profiler overlay, console, and a command system with full undo/redo. By end of phase the engine stops being a tech demo and becomes a tool a human can actually use to build a world.

## 6.1 — Editor Architecture

### Design Principles

- **Non-destructive** — every editor action goes through a command object. Full undo/redo stack. Nothing mutates engine state directly.
- **Dockable layout** — ImGui dockspace. Every panel is independently dockable, floatable, and closeable. Layout saved and restored per project.
- **Decoupled from engine** — the editor is a layer that sits above the engine. It reads engine state and submits commands. It does not call engine internals directly. This means the same engine can run headless without the editor layer compiled in.
- **Hot-reload aware** — shader hot-reload, script hot-reload, asset reimport all visible and triggerable from the editor without restarting the engine.
- **GRIA-aware UI** — alpha values, reversibility parameters, and exactness controls are first-class editor concepts, not hidden internals.

## 6.2 — Command System & Undo/Redo

Every mutation to the scene goes through a `Command` object. No exceptions. This enables unlimited undo/redo, macro recording, and eventually remote collaboration.

### Command Interface

```cpp
// editor/commands/command.hpp
#pragma once
#include "../../core/types.hpp"
#include <string>

struct Command {
  virtual ~Command() = default;
  virtual void execute() = 0;
  virtual void undo()    = 0;
  virtual std::string description() const = 0;  // shown in undo history panel
  virtual bool merge(Command* other) { return false; }  // merge consecutive drag operations
};

class CommandStack {
public:
  void execute(std::unique_ptr<Command> cmd);
  void undo();
  void redo();
  void clear();
  bool can_undo() const { return !undo_stack_.empty(); }
  bool can_redo() const { return !redo_stack_.empty(); }
  const std::string& last_description() const;
  void render_history_panel();  // ImGui panel showing all commands

private:
  static constexpr u32 MAX_HISTORY = 256;
  std::vector<std::unique_ptr<Command>> undo_stack_;
  std::vector<std::unique_ptr<Command>> redo_stack_;
};
```

### Core Commands

```cpp
// editor/commands/transform_command.hpp
struct TransformCommand : Command {
  EntityID id;
  Transform before, after;

  TransformCommand(EntityID id, Transform before, Transform after)
    : id(id), before(before), after(after) {}

  void execute() override { registry->get<Transform>(id) = after; }
  void undo()    override { registry->get<Transform>(id) = before; }
  std::string description() const override { return "Move Entity"; }

  bool merge(Command* other) override {
    if (auto* o = dynamic_cast<TransformCommand*>(other)) {
      if (o->id == id) { after = o->after; return true; }  // merge consecutive drags
    }
    return false;
  }
};

// editor/commands/entity_commands.hpp
struct CreateEntityCommand : Command {
  EntityID created_id;
  std::string archetype_name;

  void execute() override;
  void undo()    override { registry->destroy_entity(created_id); }
  std::string description() const override { return "Create " + archetype_name; }
};

struct DeleteEntityCommand : Command {
  EntityID id;
  // Serialised entity state — restored on undo
  std::vector<byte> serialised_state;

  void execute() override;
  void undo()    override;  // deserialise state, recreate entity
  std::string description() const override { return "Delete Entity"; }
};

struct ReparentCommand : Command {
  EntityID entity, old_parent, new_parent;
  void execute() override;
  void undo()    override;
  std::string description() const override { return "Reparent Entity"; }
};

// editor/commands/component_commands.hpp
template<Component T>
struct SetComponentCommand : Command {
  EntityID id;
  T before, after;

  void execute() override { *registry->get<T>(id) = after; }
  void undo()    override { *registry->get<T>(id) = before; }
  std::string description() const override {
    return std::string("Set ") + T::component_name;
  }
};

// editor/commands/sdf_commands.hpp
struct SVOCarveCommand : Command {
```

## 6.3 — Viewport Panel

The viewport is the 3D view into the scene. It renders into an ImGui image backed by the engine's output texture. It handles camera navigation, gizmo interaction, object picking, and drag-and-drop from the asset browser.

### Viewport Panel

```cpp
// editor/panels/viewport_panel.hpp
#pragma once
#include "../editor_app.hpp"

class ViewportPanel {
public:
  void render(EditorState& state, Scene& scene, Renderer& renderer,
              CommandStack& cmds, f32 dt);

private:
  // Free camera state
  struct FreeCamera {
    vec3  position      = {0, 2, -5};
    f32   yaw           = 0.f;
    f32   pitch         = 0.f;
    f32   move_speed    = 10.f;
    f32   look_sensitivity = 0.2f;
    bool  is_flying     = false;
  } free_cam_;

  // Picking
  EntityID picked_entity_   = EntityID::null();
  bool     picking_pending_ = false;
  ivec2    pick_pixel_      = {0, 0};

  void render_toolbar_(EditorState& state);
  void handle_camera_input_(EditorState& state, f32 dt);
  void handle_gizmo_(EditorState& state, Scene& scene, CommandStack& cmds);
  void handle_picking_(EditorState& state, Scene& scene);
  void render_overlay_stats_();
};

void ViewportPanel::render(EditorState& state, Scene& scene,
                            Renderer& renderer, CommandStack& cmds, f32 dt) {
  ImGui::PushStyleVar(ImGuiStyleVar_WindowPadding, ImVec2(0, 0));
  if (ImGui::Begin("Viewport")) {
    render_toolbar_(state);

    ImVec2 content_size = ImGui::GetContentRegionAvail();
    state.viewport_size = {content_size.x, content_size.y};
    state.viewport_pos  = {ImGui::GetCursorScreenPos().x,
                            ImGui::GetCursorScreenPos().y};

    // Render engine output as ImGui image (bindless texture index → ImTextureID)
    ImGui::Image((ImTextureID)(u64)renderer.output_texture_bindless_idx(),
                 content_size);

    state.viewport_focused = ImGui::IsWindowFocused();
    state.viewport_hovered = ImGui::IsWindowHovered();

    if (state.viewport_focused) {
      handle_camera_input_(state, dt);
    }

    // Gizmo overlay on top of viewport image
    if (state.primary_selection.valid()) {
      handle_gizmo_(state, scene, cmds);
    }

    // Right-click context menu
    if (ImGui::BeginPopupContextWindow("viewport_context")) {
      if (ImGui::MenuItem("Create Sphere"))
        cmds.execute(std::make_unique<CreateSDFEntityCommand>(
          SDFPrimitive::Sphere, vec3{1,0,0}, free_cam_.position));
      if (ImGui::MenuItem("Create Box"))
        cmds.execute(std::make_unique<CreateSDFEntityCommand>(
          SDFPrimitive::Box, vec3{0.5f,0.5f,0.5f}, free_cam_.position));
      if (ImGui::MenuItem("Create Point Light"))
        cmds.execute(std::make_unique<CreatePointLightCommand>(free_cam_.position));
      ImGui::Separator();
      if (ImGui::MenuItem("Focus Selected") && state.primary_selection.valid())
        focus_camera_on_(state.primary_selection, scene);
      ImGui::EndPopup();
    }

    render_overlay_stats_();
  }
  ImGui::End();
  ImGui::PopStyleVar();
}
```

### Free Camera Controller

```cpp
void ViewportPanel::handle_camera_input_(EditorState& state, f32 dt) {
  const InputState& input = Input::state();

  // Right-click held → enable fly mode
  if (input.mouse_held(MouseButton::Right)) {
    if (!free_cam_.is_flying) {
      Input::capture_mouse(true);
      free_cam_.is_flying = true;
    }

    // Mouse look
    free_cam_.yaw   += input.mouse_dx * free_cam_.look_sensitivity;
    free_cam_.pitch -= input.mouse_dy * free_cam_.look_sensitivity;
    free_cam_.pitch  = std::clamp(free_cam_.pitch, -89.f, 89.f);

    // WASD + QE movement
    vec3 forward = spherical_to_cartesian(free_cam_.yaw, free_cam_.pitch);
    vec3 right   = forward.cross({0,1,0}).normalized();
    vec3 up      = {0,1,0};

    f32  speed   = free_cam_.move_speed * dt;
    if (input.key_held(Key::Shift)) speed *= 4.f;
    if (input.key_held(Key::Ctrl))  speed *= 0.1f;

    if (input.key_held(Key::W)) free_cam_.position = free_cam_.position + forward * speed;
    if (input.key_held(Key::S)) free_cam_.position = free_cam_.position - forward * speed;
    if (input.key_held(Key::A)) free_cam_.position = free_cam_.position - right   * speed;
    if (input.key_held(Key::D)) free_cam_.position = free_cam_.position + right   * speed;
    if (input.key_held(Key::Q)) free_cam_.position = free_cam_.position - up      * speed;
    if (input.key_held(Key::E)) free_cam_.position = free_cam_.position + up      * speed;

  } else if (free_cam_.is_flying) {
    Input::capture_mouse(false);
    free_cam_.is_flying = false;
  }

  // Scroll wheel zoom
  if (state.viewport_hovered) {
    free_cam_.move_speed = std::clamp(
      free_cam_.move_speed + input.scroll_y * 2.f, 0.1f, 500.f);
  }

  // Alt + LMB orbit around selection
  // Middle mouse pan
}
```

## 6.5 — Scene Hierarchy Panel

```cpp
// editor/panels/hierarchy_panel.hpp
#pragma once
#include "../editor_app.hpp"

class SceneHierarchyPanel {
public:
  void render(EditorState& state, Scene& scene, CommandStack& cmds);

private:
  char  search_buf_[128] = {};
  bool  rename_active_   = false;
  char  rename_buf_[128] = {};

  void render_entity_node_(EntityID id, EditorState& state,
                            Scene& scene, CommandStack& cmds);
  void render_context_menu_(EntityID id, EditorState& state,
                             Scene& scene, CommandStack& cmds);
  bool passes_filter_(EntityID id, Scene& scene) const;
};

void SceneHierarchyPanel::render(EditorState& state, Scene& scene, CommandStack& cmds) {
  if (ImGui::Begin("Scene Hierarchy")) {
    // Search bar
    ImGui::SetNextItemWidth(-1);
    ImGui::InputTextWithHint("##search", "Search entities...", search_buf_, sizeof(search_buf_));
    ImGui::Separator();

    // Toolbar
    if (ImGui::Button("+ Entity")) ImGui::OpenPopup("create_entity_popup");
    ImGui::SameLine();
    if (ImGui::Button("+ SDF"))    ImGui::OpenPopup("create_sdf_popup");
    ImGui::SameLine();
    if (ImGui::Button("+ Light"))  ImGui::OpenPopup("create_light_popup");

    // Create entity popup
    if (ImGui::BeginPopup("create_entity_popup")) {
      if (ImGui::MenuItem("Empty"))     cmds.execute(std::make_unique<CreateEntityCommand>("Empty"));
      if (ImGui::MenuItem("Mesh"))      cmds.execute(std::make_unique<CreateMeshEntityCommand>());
      if (ImGui::MenuItem("Camera"))    cmds.execute(std::make_unique<CreateCameraCommand>());
      ImGui::EndPopup();
    }

    ImGui::Separator();

    // Entity tree — root entities (no parent)
    scene.registry().each<Transform>([&](EntityID id, Transform& t) {
      if (!t.parent.valid() && passes_filter_(id, scene)) {
        render_entity_node_(id, state, scene, cmds);
      }
    });

    // Click on blank area = deselect
    if (ImGui::IsMouseClicked(0) && ImGui::IsWindowHovered() &&
        !ImGui::IsAnyItemHovered()) {
      state.selected_entities.clear();
      state.primary_selection = EntityID::null();
    }

    // Drag-drop reorder
    if (ImGui::BeginDragDropTarget()) {
      if (const ImGuiPayload* p = ImGui::AcceptDragDropPayload("ENTITY_ID")) {
        EntityID dragged = *static_cast<const EntityID*>(p->Data);
        cmds.execute(std::make_unique<ReparentCommand>(dragged, EntityID::null()));
      }
      ImGui::EndDragDropTarget();
    }
  }
  ImGui::End();
}

void SceneHierarchyPanel::render_entity_node_(
  EntityID id, EditorState& state, Scene& scene, CommandStack& cmds
) {
  auto* name_comp = scene.registry().get<NameComponent>(id);
  const char* label = name_comp ? name_comp->name : "Unnamed";

  bool is_selected = std::find(state.selected_entities.begin(),
                                state.selected_entities.end(), id)
                     != state.selected_entities.end();
  bool has_children = scene.registry().has_children(id);

  ImGuiTreeNodeFlags flags = ImGuiTreeNodeFlags_OpenOnArrow
                           | ImGuiTreeNodeFlags_SpanAvailWidth
                           | ImGuiTreeNodeFlags_FramePadding;
  if (is_selected)    flags |= ImGuiTreeNodeFlags_Selected;
  if (!has_children)  flags |= ImGuiTreeNodeFlags_Leaf;

  bool open = ImGui::TreeNodeEx((void*)(u64)id.index, flags, "%s", label);

  // Selection
  if (ImGui::IsItemClicked(ImGuiMouseButton_Left)) {
    if (!ImGui::GetIO().KeyCtrl) state.selected_entities.clear();
    state.selected_entities.push_back(id);
    state.primary_selection = id;
  }

  // Drag source
  if (ImGui::BeginDragDropSource()) {
    ImGui::SetDragDropPayload("ENTITY_ID", &id, sizeof(EntityID));
    ImGui::Text("Move: %s", label);
    ImGui::EndDragDropSource();
  }

  // Drop target (reparent)
  if (ImGui::BeginDragDropTarget()) {
    if (const ImGuiPayload* p = ImGui::AcceptDragDropPayload("ENTITY_ID")) {
      EntityID dragged = *static_cast<const EntityID*>(p->Data);
      if (dragged != id)
        cmds.execute(std::make_unique<ReparentCommand>(dragged, id));
    }
    ImGui::EndDragDropTarget();
  }

  render_context_menu_(id, state, scene, cmds);

  if (open) {
    // Render children recursively
    scene.registry().each_child(id, [&](EntityID child) {
      render_entity_node_(child, state, scene, cmds);
    });
    ImGui::TreePop();
  }
}
```

```cpp
                       const char* label, Fn draw_fn);

void InspectorPanel::render(EditorState& state, Scene& scene,
                             CommandStack& cmds, MaterialSystem& materials) {
  if (ImGui::Begin("Inspector")) {
    if (!state.primary_selection.valid()) {
      ImGui::TextDisabled("No entity selected");
      ImGui::End(); return;
    }

    EntityID id = state.primary_selection;

    // Entity name (editable)
    auto* name = scene.registry().get<NameComponent>(id);
    if (name) {
      char buf[128]; strncpy(buf, name->name, 127);
      if (ImGui::InputText("##name", buf, 128)) {
        cmds.execute(std::make_unique<SetNameCommand>(id, buf));
      }
    }

    ImGui::Text("ID: %u (gen %u)", id.index, id.generation);
    ImGui::Separator();

    // Render component sections — only if entity has that component
    if (scene.registry().has<Transform>(id))    render_transform_  (id, scene, cmds);
    if (scene.registry().has<Mesh>(id))         render_mesh_       (id, scene, cmds);
    if (scene.registry().has<SDFObject>(id))    render_sdf_object_ (id, scene, cmds);
    if (scene.registry().has<RigidBody>(id))    render_rigidbody_  (id, scene, cmds);
    if (scene.registry().has<Camera>(id))       render_camera_     (id, scene, cmds);
    if (scene.registry().has<PointLight>(id))   render_point_light_(id, scene, cmds);

    ImGui::Separator();
    render_add_component_menu_(id, scene, cmds);
  }
  ImGui::End();
}

void InspectorPanel::render_transform_(EntityID id, Scene& scene, CommandStack& cmds) {
  if (!ImGui::CollapsingHeader("Transform", ImGuiTreeNodeFlags_DefaultOpen)) return;

  Transform* t = scene.registry().get<Transform>(id);
  Transform before = *t;

  bool changed = false;
  float pos[3] = {t->position.x, t->position.y, t->position.z};
  float euler[3];  quat_to_euler(t->rotation, euler[0], euler[1], euler[2]);
  float scl[3] = {t->scale.x, t->scale.y, t->scale.z};

  ImGui::PushItemWidth(-1);
  changed |= draw_vec3_control("Position", pos, 0.f, 0.f);
  changed |= draw_vec3_control("Rotation", euler, 0.f, 0.f);
  changed |= draw_vec3_control("Scale",    scl,   1.f, 0.f);
  ImGui::PopItemWidth();

  if (changed) {
    t->position = {pos[0], pos[1], pos[2], 1.f};
    t->rotation = euler_to_quat(euler[0], euler[1], euler[2]);
    t->scale    = {scl[0], scl[1], scl[2], 0.f};
    t->dirty    = true;
  }

  // On mouse release — emit undo-able command
  if (changed && ImGui::IsMouseReleased(0)) {
    cmds.execute(std::make_unique<TransformCommand>(id, before, *t));
  }
}

void InspectorPanel::render_sdf_object_(EntityID id, Scene& scene, CommandStack& cmds) {
  if (!ImGui::CollapsingHeader("SDF Object", ImGuiTreeNodeFlags_DefaultOpen)) return;

  SDFObject* sdf = scene.registry().get<SDFObject>(id);
  SDFObject  before = *sdf;
  bool changed = false;

  // Primitive type selector
  const char* type_names[] = {"Sphere", "Box", "Capsule", "Torus", "Cylinder"};
  int type_idx = (int)sdf->type;
  if (ImGui::Combo("Primitive", &type_idx, type_names, 5)) {
    sdf->type = (SDFPrimitive)type_idx;
    changed = true;
  }

  // Type-specific params
  switch (sdf->type) {
    case SDFPrimitive::Sphere:
      changed |= ImGui::DragFloat("Radius", &sdf->params.x, 0.01f, 0.01f, 1000.f);
      break;
    case SDFPrimitive::Box:
      changed |= ImGui::DragFloat3("Half Extents", &sdf->params.x, 0.01f, 0.01f, 1000.f);
      break;
    case SDFPrimitive::Capsule:
      changed |= ImGui::DragFloat("Radius", &sdf->params.x, 0.01f, 0.01f, 100.f);
      changed |= ImGui::DragFloat("Height", &sdf->params.y, 0.01f, 0.01f, 100.f);
      break;
    case SDFPrimitive::Torus:
      changed |= ImGui::DragFloat("Major Radius", &sdf->params.x, 0.01f, 0.01f, 100.f);
      changed |= ImGui::DragFloat("Minor Radius", &sdf->params.y, 0.01f, 0.01f, 100.f);
      break;
    default: break;
  }

  // GRIA Alpha — the engine's mathematical signature in the UI
  ImGui::Separator();
  ImGui::Text("GRIA Alpha");
  ImGui::SameLine();
  help_marker("α controls blend smoothness. 0 = exact Boolean, 0.5 = edge of chaos, 1 = fully smooth.");
  changed |= ImGui::SliderFloat("##alpha", &sdf->blend_alpha.value, 0.f, 1.f);
  if (sdf->blend_alpha.at_edge_of_chaos()) {
    ImGui::SameLine();
    ImGui::TextColored({0.9f, 0.6f, 0.1f, 1.f}, "⚡ chaos");
  }

  if (changed && ImGui::IsMouseReleased(0))
    cmds.execute(std::make_unique<SetComponentCommand<SDFObject>>(id, before, *sdf));
}
```

```cpp
void ProfilerPanel::render_frame_graph_() {
  // GPU frame time history — scrolling plot
  float gpu_history[HISTORY_FRAMES];
  float cpu_history[HISTORY_FRAMES];
  for (u32 i = 0; i < HISTORY_FRAMES; i++) {
    u32 idx = (history_head_ + i) % HISTORY_FRAMES;
    gpu_history[i] = history_[idx].gpu_ms;
    cpu_history[i] = history_[idx].cpu_ms;
  }

  ImGui::PushStyleColor(ImGuiCol_PlotLines, ImVec4(0.28f, 0.70f, 0.95f, 1.f));
  ImGui::PlotLines("##gpu", gpu_history, HISTORY_FRAMES, 0, "GPU ms",
                    0.f, 33.3f, {-1, 60});
  ImGui::PopStyleColor();

  f32 current_gpu = history_[(history_head_ - 1 + HISTORY_FRAMES) % HISTORY_FRAMES].gpu_ms;
  f32 current_fps = current_gpu > 0.f ? 1000.f / current_gpu : 0.f;

  ImGui::SameLine();
  ImGui::Text("%.2f ms  %.0f fps", current_gpu, current_fps);

  // 16.67ms (60fps) and 33.33ms (30fps) threshold lines
  // drawn via ImDrawList over the plot
```

```cpp
// editor/play_mode.hpp
#pragma once
#include "../scene/scene.hpp"

// Play mode snapshots the scene state, runs the simulation,
// and restores the snapshot on stop
class PlayMode {
public:
  void enter_play(Scene& scene, PhysicsManager& physics);
  void pause(Scene& scene, PhysicsManager& physics);
  void resume(Scene& scene, PhysicsManager& physics);
  void stop(Scene& scene, PhysicsManager& physics);

  bool is_playing() const { return state_ == State::Playing; }
  bool is_paused()  const { return state_ == State::Paused; }

private:
  enum class State { Stopped, Playing, Paused } state_ = State::Stopped;

  // Binary scene snapshot — restored on stop
  std::vector<byte> snapshot_;

  void take_snapshot_(Scene& scene);
  void restore_snapshot_(Scene& scene);
};

void PlayMode::enter_play(Scene& scene, PhysicsManager& physics) {
  take_snapshot_(scene);
  physics.init_from_scene(scene);
  state_ = State::Playing;
  LOG_INFO(LogChannel::Editor, "Play mode entered");
}

void PlayMode::stop(Scene& scene, PhysicsManager& physics) {
  physics.shutdown_simulation();
  restore_snapshot_(scene);
  state_ = State::Stopped;
  LOG_INFO(LogChannel::Editor, "Play mode stopped — scene restored");
}
```
